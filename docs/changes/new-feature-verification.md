### 2.1 各功能走过的流程（真实后端 + 浏览器，没有发现问题的）

- **登录页 L1–L8**：令牌使用中过期带原地址回来、密码错、重名注册、注册成功但登录失败、连按两次只发 1 次、连不上保留令牌并在恢复后直接进入、数据库不可用的提示和重新检查、退出登录。注册密码的长度边界与后端一致（7 / 8 / 128 / 129 个字符，含 emoji）
- **任务状态与重试 P1–P4**：普通用户、被共享者、管理员、无权限的人各看到什么；等待重试的任务的原因也清理过；其他接口不带出失败原因；重试权限与 409；预览页重试 → 进度 10/12 → 完成 → “有新的识别结果” → 点了才刷新 → 之后 7 秒零请求；被共享者没有重试按钮
- **P1 放行名单**：逐条看过放行类型的所有 `raise`，文字里只有数字、异常类型名、MIME、来源位置；主仓库 T24aa–ac 没有新增失败原因的写法
- **搜索动效**：OpenSearch 没启动时的真实 503、重试、扫描中改开关只显示新结果、扫描中关掉全部通道即取消、扫描中离开不留画布和隐藏标记、没有未捕获的异常
- **配色、中英文**：预设、深色、自定义颜色提示、恢复默认、Esc 关闭、本地存储损坏时回到默认；英文界面三个页面和对话框没有可见的中文（后端文字、文件名除外）；浮动按钮在对话框下面

## 3. 发现并修复的问题

### V1 轮询与刷新

| 问题 | 复现 | 原因 | 修复 |
|---|---|---|---|
| 离开预览页后一直轮询 | 文件 A 还没取回来就返回，再打开正在处理的 B，然后离开：`/tasks` 每 3 秒一次，不会停。只离开、不开 B 时会请求 `/documents/undefined/tasks` 和 `/download`（422） | `getDocument` 返回后没有看页面还在不在就 `tasks.start`；`id` 是跟着路由变的 computed | `useDocumentTasks.start` 在离开后什么也不做；预览页的 `id` 进入时就定下来，返回后先看是否已离开 |
| 离开文件列表后一直请求 | 在处理详情里重试解析任务，马上离开：`/api/documents` 每 5 秒一次 | 重试后 `onTasks`、`onQueued` 各触发一次 `load()`，两个定时器只有后一个清得掉。同时乱序返回会用旧列表盖新列表 | `LatestRun`：只认最后一次加载，离开后全部作废 |
| 一直停在“解析中” | 解析刚结束、重新取文档那一次恰好 503：状态不变，抽取文本不出现，点“刷新”也没用 | 这时任务都结束了，轮询已停；前后两次任务状态相同，`documentOutdated` 不再成立 | `Refresher`：连不上或 5xx 时每 3 秒再试，只提示一次；4xx 不再试；迟到的旧响应丢弃 |
| 后退两步从一个预览跳到另一个预览，地址变了、内容没变 | 列表 → A → 列表 → B，`history.go(-2)` | vue-router 复用同一个组件。主仓库本来就有；P4 的刷新会把两个文件的数据混在一起 | `App.vue` 的 `router-view` 加 `:key="route.path"`（切换标签页只改 query，不会重建） |

文件：`features/tasks/useDocumentTasks.ts`、`features/tasks/refresher.ts`（新增）、`utils/latestRun.ts`（新增）、`views/DocumentsView.vue`、`views/PreviewView.vue`、`App.vue`；测试 `tests/tasks/use-document-tasks.test.ts`（4 项，用 Vue 自带的 `createRenderer` 挂载，没有新依赖）、`tests/tasks/refresher.test.ts`、`tests/latest-run.test.ts`。

### V2 检索页

| 问题 | 复现 | 修复 |
|---|---|---|
| 启动动画（循环播放）与键盘操作冲突 | 焦点在“EN”按钮上、动画在播时按回车：语言没切换，焦点跳到检索框。配色面板、通道开关、导航同样 | `launch/focus.ts`：别的控件有焦点时不抢，动画照样结束；没有焦点时仍按指南 §5.3 聚焦检索框。鼠标点击的行为不变 |
| 扫描动画期间改检索词按回车没有反应 | 约 4 秒内改词按回车：只有 1 次请求，显示的是旧词的结果。与 `search-motion.md` 写的“新的检索直接覆盖旧的”不符 | “检索”按钮不再用 `:loading`（加载中的按钮是禁用的，浏览器不提交表单），与演示页一致，进度由扫描动画表示；完全相同的检索正在进行时忽略重复提交（连点只发 1 次） |

文件：`launch/focus.ts`（新增）、`launch/launchAnimation.ts`、`views/SearchView.vue`；测试 `tests/search-motion/launch-focus.test.ts`。

### V3 布局

滚到底时浮动按钮压住分页：375 px 宽压住 19 px（按钮高 32 px），1024、1280 px 宽压住 3 px，已经不能再往下滚。内容区底部内边距改为 76 px。修复后 375×812、768×1024、1280×720，中英文，文件列表、Word 预览、图片预览、检索页，重叠均为 0，没有横向溢出。登录页 L7 已单独处理，不受影响。

### V4 登录状态

连不上（L2）时点“重试”，还没返回又用表单登录：旧令牌的 401 后到，会删掉刚存的新令牌、退出登录；旧令牌仍有效时会显示成**旧令牌对应的用户**。改为：令牌已经换了，就不采用旧请求的结果（`auth.ts`），旧令牌的 401 也不触发退出（`client.ts`）。测试 `tests/auth.test.ts` 新增 3 项，修复前全部失败。浏览器里实测新用户没有被踢出。另外看到：登录后的 `/me` 要等旧的 `/me` 返回后才到达后端，应是 Chrome 对同一地址并发 GET 的排队，不是代码在等。
