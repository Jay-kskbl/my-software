## 7. 怎么重新统计

都是只读命令。净增行数（在主仓库目录）：

```bash
git diff --shortstat fd0b5eb main -- frontend/src
```

```bash
git diff --shortstat fd0b5eb main -- frontend/tests
```

这两条能代表“上传的代码”，是因为分叉点之后主仓库 `frontend/` 只有 T24v–T24z 五个提交改过（用 `git log fd0b5eb..main -- frontend` 核对）。以后主仓库自己改了前端，就要按提交逐个统计。

“相同 / 改写”的算法：用 Python `difflib.SequenceMatcher`（`autojunk=False`）找出主仓库相对 `fd0b5eb` 新增的行，再看这些行是否落在与克隆库 `de68117` 同名文件的匹配块里。注释、空行也计入。
